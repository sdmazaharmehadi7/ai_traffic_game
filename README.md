# ✕◯ Tic Tac Toe • Minimax AI & 2-Player Game

A modern, polished **Tic Tac Toe** game built with **Vite**, **React**, **JavaScript**, and **Tailwind CSS**.

---

## ✨ Features

- **🤖 vs AI Mode**:
  - **Unbeatable (Minimax Algorithm)**: Evaluates all future game states using recursive minimax search. Mathematically impossible to defeat (always forces a win or draw).
  - **Medium**: Blends heuristic moves with tactical chances.
  - **Easy**: Casual random play for beginners.
  - **Symbol Selector**: Choose to play as **X** (first move) or **O** (AI opens the game).
- **👥 2 Players (Pass & Play)**: Local two-player mode on the same device.
- **🏆 Live Scoreboard**: Tracks Player X wins, Player O / AI wins, and Draws.
- **↺ Move Undo**: Undo previous moves if you make a mistake.
- **🎉 Confetti Celebrations**: Full-screen confetti celebration on victory using `canvas-confetti`.
- **🔊 Synthetic Sound Effects**: Responsive Web Audio API sounds for placing 'X', placing 'O', win fanfare, and draw alerts. Mute toggle included.
- **✨ Sleek Neon UI**: Glowing dark theme with neon cyan 'X' and glowing rose 'O', animated turn indicators, and winning line highlights.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5175/` in your browser.

To build for production:
```bash
npm run build
```
